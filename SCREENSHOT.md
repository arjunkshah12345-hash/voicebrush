# Demo Video Notes

Record a 2–3 minute demo:
1. Hook (10s): "Soundbrush — let sound paint beautiful art"
2. Show UI, click Start mic
3. Speak softly, then louder, hum, clap — show evolving colorful trails
4. Play music briefly to show rhythm response
5. Clear, show it resets
6. Explain: mic → FFT + RMS → path strokes with glow, real-time
7. Show responsiveness

Tips: record screen + mic, cinematic, smooth.
